## Content Overview

### PDF 1: System Design Basics

This module covers fundamental concepts essential for building scalable and efficient systems:

#### **Scaling Strategies**
- **Vertical Scaling**: Adding more resources (CPU, RAM) to a single server
- **Horizontal Scaling**: Distributing workload across multiple servers

#### **Architecture Patterns**
- **Monolith Architecture**: Traditional monolithic applications
- **Microservices Architecture**: Distributed, independent services
  - Brief overview of Amazon's microservice architecture

#### **Message Queuing & Communication**
- **SQS (Simple Queue Service)**: Amazon's message queue service for asynchronous processing
- **SNS (Simple Notification Service)**: Amazon's pub/sub messaging service
- **Fan-out Architecture**: Distributing messages to multiple subscribers

#### **Performance Optimization**
- **Rate Limiting Strategies**
  - Leaky Bucket Algorithm
  - Token Bucket Algorithm

#### **Data Management**
- **Database Replication**: Ensuring data redundancy and availability
- **Caching**: Improving performance through data caching mechanisms

#### **Content Delivery**
- **CDN (Content Delivery Network)**: Distributing content across geographically dispersed servers
